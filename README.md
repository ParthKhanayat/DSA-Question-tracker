# DSA Tracker

A modern, cloud-synced web app built with React, Vite, and Supabase to track LeetCode / DSA problem-solving and revisions based on problem freshness.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm run dev
   ```
